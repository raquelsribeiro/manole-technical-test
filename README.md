# Manole Technical Test

Projeto desenvolvido para o teste técnico da Manole.

## Estrutura do projeto

- `backend/`: API REST para gerenciamento de tarefas.
- `frontend/`: Interface React para consumir a API.
- `challenges/logic/`: resolução do desafio de lógica.
- `challenges/concepts/`: respostas conceituais solicitadas no teste.

## Stack prevista

### Backend

- Node.js
- Express
- TypeScript
- SQLite
- TypeORM
- Docker

### Frontend

- React
- Vite
- TypeScript

### Qualidade

- Testes unitários no backend
- README com instruções de execução
